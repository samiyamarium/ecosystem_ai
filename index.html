Architecture Deep Dive // Layer 4

System of Record (SoR) Kernel

The foundation of the entire Agent Factory ecosystem is built around a single, consolidated System of Record. Rather than fragmenting data across disparate web APIs or legacy databases, all knowledge originates from one canonical source.

Key Components

  • Canonical Git/MDX Repository: The authoritative master copy of all books, code patterns, and specs. Every update is tracked version-by-version in Git.
  • Unified Postgres Storage: Combines relational database records, PGVector embeddings for semantic RAG, and full-text search indexing into a single engine.
  • MCP Native Protocol: Exposed via the Model Context Protocol (MCP), enabling external agents (Claude, ChatGPT, OpenCode) to read verified chapters without hallucinating.

Architecture Deep Dive // Layer 3

Modular MCP Component Packages

Instead of creating monolithic backends, capability logic is decoupled into distinct, reusable MCP Component Packages. Gateways compose these modules dynamically based on user context.

The Four Core Packages

  • content: Serves verified text, code samples, and architectural definitions directly from the SoR.
  • learning: Tracks individual learner progress, conversation history, and user state across sessions.
  • pedagogy: Encodes structured teaching moves (socratic dialogue, quizzes, error correction) as explicit agent tools.
  • builder: Assembles agent specifications, SKILL.md files, and harness templates for coding agents.
Architecture Deep Dive // Layer 2

Thin Audience Gateways

Gateways are thin interaction wrappers designed to meet users where they already work, eliminating friction and app adoption fatigue.

The Gateway Lanes

  • Zia Tutor AI (Learner Gateway): Operating directly inside Claude/ChatGPT interfaces. Greets learners, delivers adaptive lessons, and remembers history.
  • Zia Developer AI (Builder Gateway): Operating inside developer CLI tools (Claude Code, OpenCode). Selects architectures, writes specs, and implements agent code.
  • Publishing Gateway (Author Pipeline): Feeds specialized author agents canonical content to automatically adapt books for targeted verticals and domains.
Architecture Deep Dive // Economic Inversion

Connector-Native Architecture

Traditional AI applications bear expensive LLM API inference bills that cap scalability and shrink gross margins. Agent Factory flips this model upside down.

How Economic Inversion Works

  • User Brings the Model (BYOM): End users interact through their existing Claude, ChatGPT, or local LLM subscriptions.
  • Host Provides Tools & Knowledge: Agent Factory hosts light MCP servers, serving structured tools and data connectors.
  • Near-Zero Marginal Inference Cost: The platform can scale to millions of active learners without incurring massive LLM API bills.
Architecture Deep Dive // Business Model

The FDE AF 5-Layer Stack

The FDE AF Model provides a repeatable blueprint for building vertical AI business models. Every layer above the base framework generates revenue for graduates and builders.

Stack Breakdown

  • Layer 0 - Base Framework (BASE): MCP, Markdown, Postgres, vector search, auth.
  • Layer 1 - Content System of Record (EARNS): License reusable expert domain knowledge & SoR datasets.
  • Layer 2 - Teaching & Dev Ecosystem (EARNS): Low-cost education platforms at scale.
  • Layer 3 - Vertical Ecosystems (EARNS): Domain partnerships, expert digital twins, rights-cleared data.
  • Layer 4 - Customer Instances (EARNS): Field Deployment Engineer (FDE) engagements deploying customized corporate enterprise agents.
Architecture Deep Dive // Human Governance

The Outcome Architect

As AI agents become capable of writing code and assembling workflows autonomously, the strategic value shifts from manual implementation to Intent Specification.

Role & Responsibilities

  • Defining Intent: Precise articulation of what systems should accomplish, boundary conditions, and acceptance criteria.
  • System Evaluation: Setting up evals, checkers, and feedback loops to ensure agent outputs align with business metrics.
  • Orchestrating Workforce: Managing digital FTEs and human-agent teams across enterprise verticals.
